
# 4. Instrucciones para Refactorización con IA

Este documento contiene una serie de prompts o instrucciones específicas que puedes proporcionar a un asistente de IA (como Claude Sonnet 4.5, GPT-4o o GitHub Copilot) para que te ayude a limpiar y organizar el código del proyecto Agribar.

**Recomendación:** Aplica estos cambios uno por uno y verifica que la aplicación siga funcionando correctamente después de cada paso importante.

---

### Prompt 1: Organizar los Scripts de la Raíz

**Objetivo:** Mover todos los scripts de Dart que están en el directorio raíz a una nueva carpeta `tools` para separar el código de la aplicación de las herramientas de desarrollo.

**Instrucción para la IA:**
```
"Analiza el directorio raíz de mi proyecto. Crea una nueva carpeta llamada `tools`. Mueve todos los archivos con extensión `.dart` que se encuentran en la raíz del proyecto a esta nueva carpeta `tools`. No muevas ningún archivo que esté dentro de las carpetas `lib`, `android`, `ios`, etc."
```

---

### Prompt 2: Eliminar Archivos de Respaldo y Duplicados

**Objetivo:** Eliminar archivos que son copias de seguridad (`_backup`) o versiones de prueba (`.new`) y que ya no son necesarios.

**Instrucción para la IA:**
```
"Por favor, elimina los siguientes archivos de mi proyecto, ya que son copias de seguridad o duplicados innecesarios:
- `lib/screens/Empleados_content_backup.dart`
- `lib/screens/Reportes_screen_backup.dart`
- `lib/services/database_service_backup.dart`
- `lib/widgets_shared/common/custom_confirmation_dialog.dart.new`"
```

---

### Prompt 3: Eliminar Código Fuente Redundante en `windows`

**Objetivo:** Eliminar la copia duplicada del código fuente que se encuentra en el directorio de la plataforma de Windows.

**Instrucción para la IA:**
```
"El directorio `windows/lib` es una copia redundante del directorio principal `lib`. Por favor, elimina la carpeta `windows/lib` y todo su contenido."
```

---

### Prompt 5 (Avanzado): Implementar Hashing de Contraseñas

**Objetivo:** Mejorar la seguridad del sistema reemplazando el almacenamiento de contraseñas en texto plano por un hash.

**Instrucción para la IA:**
```
"Quiero mejorar la seguridad de la autenticación en mi proyecto. Realiza los siguientes cambios:

1.  Abre el archivo `pubspec.yaml` y agrega la dependencia `crypto: ^3.0.3` bajo `dependencies`.
2.  En el archivo `lib/services/usuarios_service.dart`, importa las librerías necesarias: `import 'package:crypto/crypto.dart';` y `import 'dart:convert';`.
3.  Modifica la función `_hashPassword(String password)` en ese mismo archivo. Reemplaza su contenido para que convierta la contraseña a un hash SHA-256. El cuerpo de la función debería ser:
    ```dart
    var bytes = utf8.encode(password);
    var digest = sha256.convert(bytes);
    return digest.toString();
    ```
4.  Asegúrate de que la función `validarCredenciales` y `crearUsuario` utilicen esta nueva lógica de hashing al comparar y guardar contraseñas. El flujo debe ser el mismo, ya que la función `_hashPassword` se encarga de la conversión."
```

**Objetivo:** Unificar toda la documentación en un solo lugar para facilitar su consulta.

**Instrucción para la IA:**

Resume los puntos más importantes de cada uno y agrégalos como nuevas secciones al final del archivo `DOCUMENTATION.md`. Una vez que la información haya sido migrada, elimina los archivos `DOCUMENTACION_CHEQUES.md` y `MEJORAS_NOMINA_TABLA.md`."
